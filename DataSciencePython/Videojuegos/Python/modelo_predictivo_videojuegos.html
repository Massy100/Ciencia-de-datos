Descripcion

tidymodels es el ecosistema estandar para Machine Learning en R. Unifica el preprocesamiento, modelado y evaluacion.

El dataset vgsales.csv contiene informacion sobre ventas de videojuegos, incluyendo:

  • Name: nombre del videojuego.
  • Platform: plataforma.
  • Year: año de lanzamiento.
  • Genre: genero.
  • Publisher: distribuidor/editor.
  • NA_Sales: ventas en Norteamerica.
  • EU_Sales: ventas en Europa.
  • JP_Sales: ventas en Japon.
  • Other_Sales: ventas en otras regiones.
  • Global_Sales: ventas globales.

En este modelo se intentara predecir Global_Sales, expresado en millones de copias.

Preparacion de la receta

# Establecemos la relacion para el modelo
receta <- recipe(
  Global_Sales ~ Platform + Year + Genre + Publisher,
  data = train
) %>%

  # Imputamos los años faltantes con la mediana
  step_impute_median(Year) %>%

  # Agrupamos publishers poco frecuentes en la categoria "other"
  # para evitar crear cientos de columnas dummy
  step_other(Publisher, threshold = 0.01) %>%

  # Convierte posibles categorias desconocidas en "unknown"
  step_unknown(all_nominal_predictors()) %>%

  # Convertimos variables categoricas a numericas
  step_dummy(all_nominal_predictors()) %>%

  # Normalizamos las variables numericas predictoras
  step_normalize(all_numeric_predictors()) %>%

  # Aplicamos log10 a las ventas globales
  step_log(Global_Sales, base = 10)

# Preparamos la receta
prep_receta <- prep(receta)

La receta realiza varias tareas automaticamente:

Todos los modelos utilizaran exactamente la misma receta.

Evaluacion y comparacion de los modelos

# Funcion para calcular metricas
evaluar_modelo <- function(modelo, datos_test, nombre){

  preds <- predict(modelo, new_data = datos_test) %>%
    bind_cols(
      datos_test %>%
        select(Global_Sales)
    )

  # Global_Sales se encuentra en log10 dentro de test_prep.
  # Regresamos prediccion y valor real a la escala original.
  preds <- preds %>%
    mutate(
      prediccion_real = 10^.pred,
      Global_Sales_real = 10^Global_Sales
    )

  metricas <- preds %>%
    metrics(
      truth = Global_Sales_real,
      estimate = prediccion_real
    )

  metricas %>%
    mutate(modelo = nombre)
}

# Evaluacion de los 3 modelos

Interpretacion de las metricas

RMSE indica el error promedio del modelo expresado aproximadamente en millones de copias vendidas.

R² indica que proporcion de la variabilidad de las ventas globales puede explicar el modelo.

Un modelo presenta mejor desempeño cuando tiene:

  • Menor RMSE
  • Mayor R²

  min_n = 5

La importancia de variables ayuda a identificar que caracteristicas contribuyen mas a las predicciones del modelo.

Conclusion

El documento construye y compara tres modelos predictivos para estimar las ventas globales de videojuegos:

  1. Regresion Lineal.
  2. Random Forest.
  3. XGBoost.

Los modelos utilizan como variables predictoras la plataforma, año, genero y publisher del videojuego.

La comparacion mediante RMSE y R² permite determinar cual de los tres modelos obtiene el mejor rendimiento con datos que no fueron utilizados durante el entrenamiento.

El uso de una receta comun garantiza que los tres algoritmos reciban el mismo tratamiento de datos y permite almacenar tanto el mejor modelo como el proceso de preprocesamiento para realizar futuras predicciones.
