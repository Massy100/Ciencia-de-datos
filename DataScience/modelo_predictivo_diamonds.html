Division en conjunto de Entrenamiento/Pruebas (Train/Test)

# Semilla para reproducir el modelo
set.seed(202697)

# Dividimos el conjunto de entrenamiento 80% y pruebas 20%
split <- initial_split(diamonds, prop = 0.8)
train <- training(split)
test <- testing(split)

# Establecemos la relacion para el modelo
receta <- recipe(price ~ ., data = train) %>%
  step_log(price, base = 10) %>%
  step_dummy(cut, color, clarity) %>%  # Variables categóricas
  step_normalize(carat, depth, table, x, y, z)  # Variables numéricas

# Se prepara el modelo (la receta)
prep_receta <- prep(receta)

# Aplicar la receta a train y test
train_prep <- bake(prep_receta, new_data = NULL)
test_prep <- bake(prep_receta, new_data = test)

# Verificamos
dim(train_prep)
[1] 43152    24

Descripcion

Separamos para no contaminar el modelo con datos de prueba. La receta estandariza las variables y convierte categoricas a numericas. Hacemos log(price) porque su distribucion es sesgada a la derecha.*

  • XGBoost: actualmente es uno de los mejores para datos tabulares

Evaluación y comparación de los modelos

# Funcion para calcular metricas
evaluar_modelo <- function(modelo, datos_test, nombre){
  preds <- predict(modelo, new_data = datos_test) %>%
    bind_cols(datos_test %>% select(price))

  # Deshacer el log (si aplica)
  preds <- preds %>%
   mutate(.pred_real = 10^.pred) # porque hicimos log10(price)
  metricas <- preds %>%
    metrics(truth = price, estimate = .pred_real)
  return (metricas)
}

# Evaluacion de los 3 modelos
metricas_lm <- evaluar_modelo(lm_fit, test_prep, "LM")
metricas_rf <- evaluar_modelo(rf_fit, test_prep, "RF")
metricas_xgb <-evaluar_modelo(xgb_fit, test_prep, "XGB")

# Mostrar comparativa
bind_rows(
  metricas_lm %>% mutate(modelo="LM"),
  metricas_rf %>% mutate(modelo="RF"),
  metricas_xgb %>% mutate(modelo="XGB")
) %>%
  filter(.metric %in% c("rmse", "rsq")) %>%
  select(modelo, .metric, .estimate) %>%
  pivot_wider(names_from = .metric, values_from = .estimate) %>%
  arrange(rmse)
